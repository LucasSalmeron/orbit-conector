# Orbit Conector

Programa que corre en cada caja de Orbit e imprime los tickets directo, sin diálogo, en la impresora
que corresponde a cada rol.

**Para instalarlo:** desde Orbit, Configuración → Impresión → Descargar. O bajá
[OrbitConector-Setup.exe](https://github.com/LucasSalmeron/orbit-conector/releases/latest/download/OrbitConector-Setup.exe)
y abrilo.

Una vez instalado se actualiza solo, en un momento en que no se esté imprimiendo.

Este repositorio solo tiene los [releases](https://github.com/LucasSalmeron/orbit-conector/releases).
